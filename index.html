📦 Static API

Este repositorio expone endpoints JSON estáticos utilizando GitHub Pages. Simula una API REST simple (solo GET), ideal para pruebas, mocking de integraciones y prototipos rápidos.

🌐 Endpoints disponibles
  • responder.json
  • transferir.json
  • adjuntar.json
  • desconectar.json
📁 Ejemplos generales
  • data.json → OK
  • data-error.json → error
  • data-timeout.json → timeout
  • data-notfound.json → not found
⚙️ Ejemplo de uso
curl https://juarezgerman.github.io/static-api/responder.json
